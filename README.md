# Cloud-Based Bus Pass System

## Project Description
The Cloud-Based Bus Pass System is a simple web application that helps users apply for a bus pass online. It displays passenger details, bus route, pass duration, price, and booking confirmation.

## Objectives
- To make bus pass booking simple and easy.
- To reduce manual work.
- To calculate bus pass prices automatically.
- To display booking confirmation.

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- Google Colab
- GitHub

## Features
- Passenger name entry
- Bus route selection
- Monthly, 3-month, and 6-month pass options
- Automatic price calculation
- Booking confirmation with booking ID

## How to Run
1. Open Google Colab.
2. Upload and open `Cloud_Bus_Pass_System.ipynb`.
3. Run the code cell.
4. Enter passenger details.
5. Click the Book Bus Pass button to view the confirmation.

## Conclusion
This project demonstrates a simple online bus pass booking system. It provides an easy way to enter passenger details and display bus pass information.

**Note:** This is a beginner-level prototype. Cloud deployment and permanent data storage are not included.
